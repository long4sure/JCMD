About JCMD

Simple tools.

JCMD is a simple tech project based in Calamba City, Laguna. JCMD builds friendly websites and easy-to-use tools for local shops, cafes, and community organizations. Good software should be accessible to everyone, which is why everything built by JCMD is 100% free and open-source.

JCMD focuses on making things simple: pages that open instantly on mobile phones, offline point-of-sale systems that run right in your browser, and straightforward guides. There is no need for expensive monthly subscriptions or complicated setups.

Whether you run a neighborhood coffee shop, a family karinderya, a retail store, or a local club, JCMD is ready to help organize daily work and showcase services beautifully.

FAQ

Common Questions

Are the POS registers and ERP demos completely free? ▼
Yes! The Point-of-Sale registers, general retail directories, and the Brew & Bean cafe dashboards are open-source and free to launch directly in your browser. JCMD created a local storage database simulator so you can catalog items and process orders locally without paying any backend hosting fees.
How does the Library Management System (LMS) work? ▼
The LMS is a native, offline-capable desktop cataloging and lending system built in Java. It packages all files, launchers, and a local SQLite database into a single compact folder. You simply download the portable ZIP, extract it, and click launch—no server, internet, or databases configuration required.
Is the website hosting truly free? Are there any hidden fees? ▼
Absolutely no catch. Static HTML/CSS/JS websites contain no server-side compilation, meaning platforms like GitHub Pages and Netlify host them completely free of charge. The only yearly cost is a custom web domain (e.g. yourbusiness.com), which costs around ₱800–₱1,200 per year, paid directly to registrars like Namecheap.
Can we add online ordering or real-time appointment bookings? ▼
JCMD builds clean static sites, which do not contain heavy database architectures for live online payment processing. Instead, JCMD configures simple, high-efficiency email inquiry forms, call-to-order triggers, and floating Facebook Messenger chat buttons which work exceptionally well for local businesses!
Are you based in Calamba City? Can we coordinate in person? ▼
Yes! JCMD is based in Purok 4, Asia 2, Brgy. Canlubang, Calamba City, Laguna. JCMD is happy to coordinate directly to design systems with clients around Calamba and neighboring areas (Los Baños, Cabuyao, Santa Rosa). For clients elsewhere, everything can be handled smoothly via Messenger or email.
